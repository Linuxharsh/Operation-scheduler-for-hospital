# Operation Scheduler for Hospital Management

## Technologies
HTML, CSS, JavaScript, Firebase

## Modules
- Admin
- User

## Features
- Doctor Management
- Operation Theater Scheduling
- Dynamic OT updates
- Logging for every action
- Firebase Authentication & Firestore

## Workflow
1. Admin logs in
2. Admin manages doctors & OT schedules
3. Users view surgery schedules and doctors
4. Logs maintained for all actions

## Deployment
Hosted using Firebase Hosting

## Testing
- Auth testing
- CRUD testing
- Schedule conflict testing

## Optimization
- Modular JS
- Firestore indexing
- Reusable UI components
